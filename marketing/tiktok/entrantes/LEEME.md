# Clips e imágenes de Gemini para editar

Subí acá las imágenes (Nano Banana) y los videos (Veo) que generes en la app de Gemini o en Flow.
Después avisale a Claude, que los baja, los edita (ritmo, subtítulos, precio, código TIKTOK) y sube el video final a Drive.

## Cómo subirlos desde la web de GitHub (sin instalar nada)
1. Entrá a esta carpeta en GitHub: `marketing/tiktok/entrantes` (rama `main`).
2. Tocá **Add file → Upload files** y arrastrá los archivos (hasta 25 MB cada uno).
3. Abajo, en "Commit changes", dejá **Commit directly to the main branch** y tocá **Commit changes**.

Nombres sugeridos: `cafe-1.mp4`, `aeropuerto-1.mp4`, `billetera-1.png`.

Esta carpeta no se publica en la web (el sitio bloquea `/marketing/`).
